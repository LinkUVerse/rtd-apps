# Git 交付范围

更新日期：2026-10-12。

按项目所有者要求，Git 仅交付工程源码、测试与部署脚本、构建配置、技术文档、任务进度账本和文字工作日志。

`evidence/` 的原始数据、`workLog/` 内的请求抓包、JSON 验收输出、历史输入及源码快照、截图、录像和其他运行产物保留在本机，并由本目录 `.gitignore` 排除。证据目录中的可执行审计源码和文字说明可入库；`workLog/current-data-lifecycle-progress.json` 属于进度账本，随文档提交。

工作日志中的原始证据路径及摘要保留其历史含义。远端克隆仅包含工程与文字记录，不附带这些本地验收数据；不能把缺失的原始文件当作一次新的验收通过。需要复验时使用已提交的脚本和指定开发环境重新生成证据。

本次不发布 `RTD-Blockchain/temp` 中的历史仓库副本，也不上传私钥、账户库、开发数据库、Chrome profile、依赖缓存或编译目录。编译器/链协议必需且原本作为源码管理的固定框架快照不属于浏览器验收数据。
