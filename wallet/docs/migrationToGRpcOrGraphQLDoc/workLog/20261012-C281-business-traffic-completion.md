## 联合审核

- [流量审核](./20261012-C281-business-traffic-01.json)：25 份普通 Chrome HAR，去除重叠导出前缀后 3,918 次请求。Fullnode 1,651、GraphQL 2,095、archive 143、独立 account 22；另有本地 Display 夹具图片 7 次。
- 全部捕获目的地均为明确的本地测试入口，未发现 JSON-RPC 请求或公网 Sui 查询。GraphQL 请求语法、响应 envelope 和存在时的 H0 已核对；原生成功响应完整校验 gRPC-Web 帧、protobuf schema、trailer/status，GetServiceInfo 校验所属代次的 H0。
- 6 笔不同摘要的实际成功执行逐笔重新验证原交易字节、发送人、H0、签名和成功 effects；重复 HAR 不算重复执行。这次审核自身网络请求、模拟、签名、广播均为 0。
- 254 条非成功或正文不足的捕获保留：203 条 HTTP 0、8 条 HTTP 503、43 条 HTTP 200 但正文缺失／gRPC 错误等。它们未算成功业务读取；相应正向闭环由下列原始业务证据支持。

该结论针对实际捕获的流量；不把有限抓包说成所有未来时刻的网络保证，也不把 GraphQL envelope 校验冒充每条读取的业务语义验收。原业务语义、界面、失败分支和写后结果复用以下已通过证据。

证据版本和链代次保持独立：G3 来源继续注明 G3，G4 写后案例继续注明 G4。全生命周期与冷恢复仍在 QA-A17／QA-A20 中推进，不以本项完成代替它们。
