# C146 重启后仅恢复钱包迁移环境

主人本次明确要求只恢复钱包新 RPC 对接所需环境，并清理已废弃的历史临时容器、镜像。本操作不启动其他开发项目。

1. 冻结本次系统 boot、全部容器配置及当前 RTD 源码与 8 个 debug 产物。已确认 36 个仍有用途的钱包容器，另外 83 个不在启动集合。
2. 依次恢复既存 PG、S3、ZooKeeper、HBase、gateway、副本及传输边缘。使用确切容器 ID 启动，保留原卷和数据库，不执行初始化、镜像拉取或重建。
3. G3 承担当前迁移验证，G0 承担原链恢复与对照，两组不同创世身份仍有用途。沿用既存数据及原始启动命令；G3 的 200ms 参数只从其创建时证据恢复，G0 使用原默认参数。
4. 重启已经结束旧进程。旧 PID、出生时间、容器 StartedAt 和健康报告均为历史事实，不能再用作当前授权。新增本次启动登记，保留旧报告；真实 gRPC 身份和 checkpoint 推进通过后才标记节点 ready。
5. 查询、账户、发布与完整回放消费者必须按依赖恢复并获得本次出生身份。发布 fencing、实际权限及源数据检查继续执行，不能通过修改历史证据或手动抬升水位绕过。
6. 清理前核查当前配置和容器引用，逐个记录废弃理由及确切 ID。仅删除确认废弃且已停止的本任务容器，保留数据卷、验收 profile、共享镜像和其他项目资源。

环境启动和进程运行不计入 TX-01/TX-04 或原 98 项业务验收。待当前接口实际可用后继续优先非 NFT 签名授权与持久恢复，不能重放旧签名/执行请求。
