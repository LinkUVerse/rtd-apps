# NET-02 / RPC-05：显式配置与资产快照读取

日期：2026-10-03（北京时间）。关联 NET-02、NET-04/05/06/08/09/11/12、RPC-01/02/03/04/05/07。只有 NET-02 和 RPC-05 达到本项编码与定向验证要求，本轮勾选；其余仍实施中。

## 已落地

- 新增原生 GraphQLSnapshot：逐项读取 `serviceConfig.availableRange`，取交集选 S；用 `Checkpoint.query` 固定领域查询。所有请求重验完整 H0、S/digest 与依赖覆盖，拒绝部分错误、缺字段、已裁剪或变更的快照。
- 新增 WalletAssetReader：全部余额、元数据、拥有 Move 对象、展示用 Coin、批量 Move 对象。余额由 decimal string/BigInt 校验 coinBalance+addressBalance=totalBalance；必需字段缺失不能补零。批量明确 null 产生逐项 ObjectError 并保留请求位置，缺位置／错 ID／缺内容拒绝整批。
- 全分页在本地暂存，终页复验后交付。重复项、停滞 cursor、项目／页数预算截断失败关闭，允许前进的空扫描页。
- 新增共享 core 的 WalletRpcContext 与钱包 WalletRpcProvider；配置状态显式区分 unconfigured/invalid/initializing/configured。configured 仅表示存在配置与读取会话，**不宣称**三入口能力／package／执行 ready。
- 内置新读取路径使用显式 `WALLET_NETWORK_PROFILES` v2 JSON；默认 `{}` 不推导旧单 URL，不访问 SDK 默认 MVR。legacy customRPC 在 storage/UI v2 完成之前返回未配置，不猜测绑定。
- 首页／资产卡／币列表／推广余额通过自有 useGetAllBalances 查询，TokenDetails 单币展示从完整已准入集合选取；余额失败显示错误，元数据未知不能由本项宣称其页面已迁完。排序使用 BigInt，不改变原快照数组。
- query cache 保留快照 proof，按完整网络绑定＋独立 read session＋owner 取键，冷启动／重入相同 profile 重新准入；该资产查询暂不持久化，网络切换取消旧读取。转账完成后新的资产查询前缀刷新。
- moduleResolution 改为 bundler，正确读取现代 SDK 的 exports；没有伪造旧 SDK DTO 或添加 JSON-RPC fallback。

## 权威与协议核对

查询了 [Sui 官方 GraphQL scope/retention 文档](https://docs.sui.io/develop/accessing-data/graphql/query-with-graphql)，保存官方 SDL 的固定提交 `c860146823abcedef45a1b5a9c766920be98a29c` 原文与 SHA-256 于 [manifest](../evidence/official/sui-snapshot-manifest.json)。此提交两个 Rust 源码路径下载返回 HTTP 404，**不记为已读取**；判断依据为成功获取的官方文档／SDL，以及已核对的本地 RTD Rust available_range 与 SDK GraphQL 源码。

受控 Fetch 中的每条准入、分页、详情、复验查询都经本地 RTD SDK SDL 和固定官方 Sui SDL 双重验证；对后者只转换地址 scalar 名称。两侧技术方案已同步补充相同原生快照合同，原 archive 目录保留。
