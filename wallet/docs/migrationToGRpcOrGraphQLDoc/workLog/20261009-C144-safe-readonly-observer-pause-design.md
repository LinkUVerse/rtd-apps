# C144只读观察器暂停的安全等待边界

新查询容器仍必须等待C141指定完整独立审核通过。只读观察器也不能在正在执行SQL/HTTP/fsync/更新器时任意SIGSTOP，否则正常恢复可能让挂起中的请求过期并导致原观察器退出；原七出生身份不能据此丢失。

旧原观察器源码不修改。暂停前核对同PID出生、同观察器源码SHA、当前完整41管线只读报告及原六consumer PID；报告时间经过25秒而不超过40秒才进行一次自有sample观察。原源码的进度写入之后，唯一更新器有20秒timeout，随后为60秒time.sleep；还须实际栈包含time_sleep、采样前后报告未变化、PID未变化、sample≤6秒、墙钟与本进程monotonic经过差≤0.5秒、结束时报告年龄≤45秒。整个等待最多120秒；不符合时在SIGSTOP之前封闭拒绝，不强行恢复/重启原进程。

这不是暂停有写入权的owner，不影响两组链/indexer、原publisher或C139六consumer。实际sample记录仅留本任务0700目录及SHA，不返回Python变量、密码或私钥。后续范围捕获、明确3CID归属、独立只读观察接续、正常清理和同出生恢复保持；原证据/源不覆盖，派生v4及完整逆变换另验。

本文件仅实施前合同，不记录实际暂停、实际sample或完整cold通过。
