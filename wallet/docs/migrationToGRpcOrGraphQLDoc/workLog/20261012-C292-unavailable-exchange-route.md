# C292 兑换未开放入口的一致性修复

C291逐路由终核发现，首页已明确兑换未开放，但直接进入 `usdc-promo` 仍加载外部USDC图片，并带按钮跳转至不存在的 `/swap`。这不是有效的兑换能力，也不应展示成可用入口。

现已将该页改为与首页相同的双语“当前网络尚未开放兑换”提示，保留返回入口；删除外部推广图片、旧币种常量、兑换CTA及对应推广事件。本次唯一产品模块变化为 `UsdcPromo.tsx`，不改变账户、RPC、权限、网络及manifest。

验证：11项既有Token页面测试、RPC/生产两项类型检查、完整生产编译及全产物依赖闭包审核通过。[候选审核](./20261012-C292-ordinary-upgrade-prepared-01.json)逐模块确认唯一变化，完整C278原产物仍在安装路径，C292在隔离候选目录。

macOS锁屏使普通C51界面操作尚不能继续。本次候选**未安装**，C278当前直接路由仍有原问题。恢复电脑操作后利用既有升级授权执行原路径升级、保留C278和账户，再实际验收直接入口、首页和返回行为。不能把源码修复/构建通过当作已安装或真实页面通过。

[逐RPC/页面追溯](./20261012-C291-rpc-page-traceability.md)覆盖21项旧RPC和54条路由，列出每项证据版本与原范围；REL-05.5继续开放。密码恢复、Qredo、旧未挂载Token路由等例外按实际来源保留，未伪造已测。
