# C213：Fullnode 业务读取复用与合并候选

## 实现与范围

相同 WalletReadSession、fetch 传输、超时、方法和完整 protobuf 请求，仅在尚未发出的队列中共享一次 GetBalance/GetObject/ListOwnedObjects。请求编码包含账户、币种、对象、readMask、pageToken。发出前立即移除队列条目，不复用进行中或已完成观察。每个调用者保留读取前后的链身份和水位检查、对象/余额/分页解码校验及自身预算；响应逐调用者克隆，避免 Uint8Array 等可变字段相互污染。

取消一个调用不影响其余调用，全部取消才取消底层传输；会话关闭仍拒绝迟到响应。不同会话、传输、超时、方法、请求字节均隔离；不改变模拟、签名、执行行为，不设置全页面查询次数上限。

C213 合并 C211 的同快照重型 GraphQL 合并及短时页面缓存优化。C211 没有安装，当前独立 C51 仍为 C210；最新 C213 具体升级确认已发出，不能把候选或源码 CLI 当作新版浏览器验收。
