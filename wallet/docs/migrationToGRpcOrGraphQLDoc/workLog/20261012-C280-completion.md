## 缺陷与修复

本轮发现归档 Guard 的 Python PID 1 不响应 SIGTERM。源码已补正常 shutdown 处理，52 项测试及两个真实隔离容器信号测试通过，随后仅替换 G4 Guard 镜像；真实生产容器 SIGTERM 正常 exit 0，用时约 0.925 秒，恢复后 mTLS、只读角色、原始 checkpoint SHA、错误路径和缺证书拒绝通过。其他 129 个容器、13 个原生进程保持。[C282 部署证明](./20261012-C282-guard-installed-01.json)。

比较工具单侧 undefined 规范化、镜像 FROM 原始 ID 以及隔离容器就绪竞态的失败均保留并修正；这些工具失败未转换为产品缺陷。详细过程见[C280 过程](./20261012-C280-cold-in-progress.md)。
