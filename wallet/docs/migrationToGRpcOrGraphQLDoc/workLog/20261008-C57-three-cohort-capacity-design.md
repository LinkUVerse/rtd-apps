# C57：三cohort容量与物理隔离前置

在任何新完整三cohort写入或扩容前，先核对真实guard镜像的16槽位、16只读PG池、实际adapter12和三个当前fixed4。本地server默认8、旧adapter工具4／6和上游默认并发不能当作当前dev配置。读取实际冻结模块和容器内代码，不改image、配置、端口或源码。

C55 SQL-only8的有限样本有收益；8×3=24超过现12 adapter与16 guard，不能照抄到生产。新合同须明确各层共享或独立预算和失败关闭，全部原fresh catalog、SQL、marker、固定GET、副本和二次检查保持。Sui官方固定／自适应控制属于每个IngestionService及其慢subscriber背压，不能自动为独立部署的三cohort分配共享容量。

RTD HBase网关的tableName只返回白名单表尾，project／instance不形成物理namespace。独立HBase试验必须使用独立物理HBase、root／WAL／ZK及明确新bucket、凭证和网关，不能仅换instance去碰原14表。先核对实际已安装gateway.jar内对应方法，再准备独立完整试验，0原业务表写入。
