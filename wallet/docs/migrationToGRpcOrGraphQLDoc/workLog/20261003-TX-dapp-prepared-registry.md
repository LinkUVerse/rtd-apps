# dApp最终交易字节的后台批准凭据

日期：2026-10-03；RPC-15／TX继续实施，未完成整体。

新增DappPreparedRegistry，并由后台prepareDappTransaction在前后授权复核成功后登记。只复制最终bytes／digest和请求／账户／网络／origin／原文hash／模式绑定；返回随机UUID凭据与五分钟期限。默认最多32项，同请求新预览撤销旧凭据；消费同步删除，随后校验全部绑定，重复或错绑定消费失败。保持纯进程内存，不向journal写交易字节／签名，worker重启需重新预览。revokeRequest／clear方法供后续请求／会话生命周期接入。

新增12项测试，检查不可变字节、全部绑定维度、精确到期边界、容量、替换、清理和新实例无法复用旧凭据。相关3文件31/31通过，RPC类型检查通过；完整钱包仍107条诊断。见同日dapp-prepared-registry-tests.log、rpc-typecheck.log及typecheck.log。

注意：当前尚未接入生产签名消费、批准页后台预览替换、取消／断连撤销事件。模块消费规则不是完整签名防重放验收；返回凭据不能代替签名前重新读取请求、权限及真实网络身份。下一步复用授权边界接签名和单次执行，再替换UI批准提交。无新增dev、部署、实链或Chrome证据，当前不可试用。
