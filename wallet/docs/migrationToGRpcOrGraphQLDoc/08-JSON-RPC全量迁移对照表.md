## 1. 范围、计数与服务约定

- 扫描 **552 个文件**；收集 60 个调用候选、3 个 RPC 字符串候选，逐项分类；没有发现动态 Hook 方法选择器或 SDK 方法别名。
- **21 个实际使用的独立 JSON-RPC 线协议方法**，包括直接调用、Hook、原始 fetch、间接调用与可关闭的 zkLogin 残留；同一方法不重复计数。
- 当前目标 SDK JSON-RPC 客户端另有 **18 个钱包未调用的方法**，单列附录；主表与附录合计 **39 个互不重复的方法**。附录不能据此扩大钱包实施需求。
- `getChainIdentifier`、签名／执行封装、构建器和等待封装是组合函数，不是新增独立 RPC；第 4 节给出落点。Sentry 规则字符串和 Object.prototype.hasOwnProperty.call 不计作网络调用。

| 缩写／服务 | 本文具体含义 | 浏览器交付条件 |
| --- | --- | --- |
| Fullnode gRPC | `rtd` 全节点，`rtd.rpc.v2.LedgerService`、StateService、TransactionExecutionService、MovePackageService、NameService 等 | 使用同链 Fullnode 的 gRPC-Web 入口；构建、模拟、提交、当前确认路由到这里 |
| GraphQL（归档项目子服务） | **`rtd-archive-service` 部署的独立 `graphql` 子服务**，运行 `rtd-indexer-alt-graphql rpc`；钱包经该项目 HTTPS 网关访问 | 使用 RTD 当前 SDL 的 typed query／新 RtdGraphQLClient；固定会话快照与覆盖检查 |
| 归档 gRPC | `rtd-archive-service` 的 Ledger／MovePackage 历史服务 | 原生服务仍为HTTP/2；受控gRPC-Web桥接已经部署，C281/C280有实际Chrome读取及冷恢复证据 |

表中的 `服务/方法` 是 gRPC 线协议名；TypeScript 使用小驼峰 raw client 方法。`client.getObject` 等新 SDK 方法并不必然对应同名 raw RPC。例如 gRPC `getObject` 使用 BatchGetObjects，listCoins 使用 ListOwnedObjects，getCoinMetadata 使用 GetCoinInfo。

### 1.1 GraphQL 由谁提供

**本文主表、调用索引及附录中所有“GraphQL”目标，均指 `rtd-archive-service` 中的 GraphQL 子服务；钱包不向 Fullnode 发起 GraphQL 请求。** Fullnode 提供的是本方案另一条入口——Fullnode gRPC／gRPC-Web。两者即使共用公开域名，也须按路径配置各自客户端。

| 项目／组件 | 实际提供的入口与职责 | 与 Fullnode 的关系 |
| --- | --- | --- |
| `rtd-archive-service` → `graphql` | 独立索引查询进程 `rtd-indexer-alt-graphql rpc`，容器内部监听 `7000`；提供原生 GraphQL SDL 中的对象、余额、交易、事件、名称等查询 | 读取 PostgreSQL 索引、Consistent Store 和归档 `kv-rpc`；必要功能通过配置的 `--fullnode-rpc-url` 访问同链 Fullnode。**这是后端依赖，不代表 GraphQL 运行在 Fullnode 中** |
| `rtd-archive-service` → `query-ingress`、`account-query-edge` | 查询准入／HTTP 转发与 HTTPS／TLS 入口；把原生 `/graphql` 请求路由到 `graphql` 子服务 | 网关不是 Fullnode，也不是实际 GraphQL 查询引擎 |
| `rtd-archive-service` → `account-history` | `/account/graphql` 上的账户收支领域扩展；与原生 GraphQL 是不同服务、不同字段集合 | 请求只路由到账户历史服务，不能向 Fullnode 或原生 GraphQL 发送 `accountHistory` 字段 |
| `rtd` → Fullnode | 全节点 RPC listener，承接钱包实时读取、构建、模拟、提交与近期确认所用的 gRPC／gRPC-Web | GraphQL 子服务可把 Fullnode 当下游；钱包通过独立 Fullnode 客户端直接调用本表标为 Fullnode 的方法 |
